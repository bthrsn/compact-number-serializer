Решение задачи компактной сериализации множества целых чисел с гарантированным сжатием минимум в 2 раза.
Задача
Есть множество (массив, где порядок не важен) целых чисел в диапазоне от 1 до 300. Количество чисел - от 5 до 1000.
Простейший алгоритм сериализует множество в строку вида "1,300,237,188".
Цель: Написать функцию сериализации/десериализации в строку, чтобы итоговая строка была компактной (итоговая строка должна быть в 2 раза короче простейшей сериализации для любых возможных наборов чисел).
Требования

Максимально сжать данные относительно простой сериализации
Без использования готовых алгоритмов сжатия (gzip, lz4, и т.д.)
Сериализованная строка должна содержать только ASCII символы
Гарантия сжатия минимум в 2 раза для любых наборов чисел

Решение
Алгоритм
Решение использует комбинацию трёх техник оптимизации:
1. Base64-кодирование чисел
Вместо десятичной системы (10 символов: 0-9) используется 64 ASCII символа (A-Z, a-z, 0-9, +, /).
Десятичное: 300 → "300" (3 символа)
Base64:     300 → "Es"  (2 символа)
2. Диапазонное представление последовательностей
Последовательные числа кодируются как диапазоны в формате start-length:
[1,2,3,4,5] → "B-F" вместо "B,C,D,E,F"
[100,101,102,103] → "Bk-D" вместо "Bk,Bl,Bm,Bn"
3. Умный выбор представления

Диапазоны ≥3 элементов → всегда используется диапазонное представление
Диапазоны из 2 элементов → выбирается более компактное представление
Одиночные числа → кодируются отдельно

Минимальное сжатие во всех случаях: >2x ✓

Технические детали
Структура сжатой строки
Format: "part1,part2,part3,..."

part = одиночное_число | диапазон
одиночное_число = base64_encoded_number
диапазон = base64_start "-" base64_length

Примеры:
"B"      → [1]
"B-D"    → [1,2,3]
"B,E"    → [1,4]
"B-D,E"  → [1,2,3,4]
Base64 кодировка
Используемый алфавит: ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/
Число → Base64
1     → B
10    → K
64    → BA
100   → Bk
300   → Es
